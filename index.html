A benchmark for how well AI coding agents optimize LLM decoding

I designed and built an accepted benchmark task. An agent gets batched decoding for a small LLM on a single GPU and is scored on how much faster it makes it, while the outputs stay within tolerance of an independent reference.

Model
Qwen2.5-1.5B
Hardware
NVIDIA H100
Scoring
Geometric-mean speedupacross four workloads
Memory cap
40 GiBpolled at the driver

What the agent has to find

  • Kernel-launch overhead, addressed with CUDA graphs and torch.compile.
  • Attention wasted on padded sequences in a mixed-length batch.
  • Long-context attention: split-K (flash-decoding) written in Triton, with grouped-query attention.

How a result is verified

  • Teacher-forced inputs, so every submission sees the same token stream.
  • Per-position checks of full logits against an independent fp32 reference, with top-1 tolerance and KL-divergence bounds.
  • Held-out evaluation prompts the submission never sees while it is being tuned.

How it resists reward hacking

  • Signed engine replies, so results cannot be forged.
  • Source scanning for process and socket escapes.
  • Driver-level GPU memory polling against the 40 GiB cap.
  • Timing functions bound before the submission loads, so the clock cannot be patched.
